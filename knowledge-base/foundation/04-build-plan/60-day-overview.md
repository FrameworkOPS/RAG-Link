## Build philosophy

Every build in this plan maps to either:
- (a) closing first 3 clients, OR
- (b) delivering to them efficiently

If neither, it's cut. See [[build-philosophy]].

## What's deliberately NOT being built

## Hard rules

1. **Launch date is fixed.** July 5, 2026. Slipping = compounding revenue loss.
2. **If hours drop below 30/week target,** recalibrate scope, don't slip launch.
3. **Sunday 7pm PT checkpoint is non-negotiable.** Honest "done/not done" assessment.
4. **Daniel engagement hours are capped weekly.** Cannot expand to consume Framework OPS build time.

## Failure mode: Infinite preparation

The #1 risk for a disorganized founder building pre-revenue is **infinite preparation that delays revenue.**

Mitigation:
- Hard launch date on calendar (done)
- 80% solutions ship; perfectionism slides the launch
- Build-in-public on LinkedIn — visible progress accountability
- Weekly checkpoint forces honest assessment
