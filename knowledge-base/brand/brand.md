# Framework OPS — Brand Reference

Visual identity for Framework OPS client deliverables. Derived from
frameworkopsllc.com.

## Logo

`framework-ops-logo.png` — the grid mark: a 3×3 grid of rounded squares that
dissolves into dots toward the bottom-right corner. Emerald green on transparent.
Source geometry (SVG viewBox 0 0 34): rounded rects (8×8, r 1.6) at (3,3) (13,3)
(23,3) (3,13) (13,13) (3,23); dots (r 1.8) at (27,17) (17,27) (27,27).

Wordmark: "FRAMEWORK" in navy + "OPS" in green, bold, set beside or below the mark.

## Color palette

| Role | Hex |
|------|-----|
| Primary green (accent) | `#10B981` |
| Dark green | `#059669` |

| Light surface | `#F1F5F9` |

## Typography

- Web uses system sans-serif; documents use **Arial** (universally available).
- Headings: bold, brand navy, with a thin green underline rule.

## Usage

- Logo + green accent rule on covers and page headers.
- Navy for headings and body emphasis; green for labels and accents.
- Keep deliverables clean and white-background — green and navy do the work.
