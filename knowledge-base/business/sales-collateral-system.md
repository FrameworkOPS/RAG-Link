# Framework OPS Sales Collateral System

This note documents the current sales collateral package for Framework OPS. The package is designed around one operating rule: diagnose first, then recommend one path. It should support the actual selling motion without turning the offer into a menu.

## Sales Workflow Supported

The visual journey follows six stages:

1. Discovery - qualify revenue, owner role, pain, budget, urgency, and red flags.
2. Intake - collect written business overview, org chart, tech stack, financial snapshot, and top problems.
3. OPS Assessment - run the paid diagnostic and rank operating gaps.
4. Proposal - present one recommended path with named deliverables, timeline, investment, and conservative ROI.
5. Agreement - collect signature and first payment before kickoff.
6. First 90 days - install operating systems, SOPs, dashboards, handoffs, and cadence.

The OPS Assessment remains the gateway. Do not visually or verbally imply that a prospect should jump from discovery directly into a retainer unless the diagnostic has already happened elsewhere and the data is current.

## Workbook Tabs

The sales workbook contains:

- `Start Here` - operating rules for using the workbook.
- `Pipeline Tracker` - CRM-lite tracker for LinkedIn, referrals, warm intros, and inbound leads.
- `Fit Scorecard` - prospect qualification math and Go / Wait / No-Go flag.
- `Discovery Call` - 30-45 minute discovery capture sheet.
- `Offer Router` - one-path recommendation logic across entry products, sprints, and retainers.
- `ROI Snapshot` - conservative value framing for proposals.
- `Follow-Up Cadence` - simple timing and message jobs for each sales moment.
- `Lookups` - source-of-truth status and offer values.

## Guardrails

- Do not pitch a retainer as the first move to cold or lightly qualified prospects.
- Do not present every tier in a proposal.
- Do not skip the OPS Assessment unless the diagnostic evidence already exists.
- Do not use upside-only ROI math.
- Do not discount to close. Scope down instead.
- Do not automate a process before the manual process is stable.
